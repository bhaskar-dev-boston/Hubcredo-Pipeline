Build a full-stack Next.js web application called HubCredo — a guided sales infrastructure platform for founders. The app takes a website URL, scrapes it via n8n/Apify, extracts ICP signals using Groq LLM, lets the founder confirm their ICP through a wizard, then generates a LinkedIn lead list and recommends a tool stack.

Tech Stack

Framework: Next.js 14 (App Router)
Styling: Tailwind CSS
Auth + Database: Supabase (provided credentials below)
Automation: n8n webhooks (URLs provided below)
Language: TypeScript


Environment Variables
Create a .env.local file with these variables:
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key

n8n Webhook URLs

Website scraping + ICP extraction: https://shreyahubcredo.app.n8n.cloud/webhook-test/lead-scrapping

Triggered when user submits their website URL
Payload: { user_id, website_url, analysis_id }
n8n will crawl the website via Apify, extract keywords and ICP signals via Groq, and write results back to Supabase company_analyses table


Lead list generation: https://shreyahubcredo.app.n8n.cloud/webhook-test/lead-scrapping-list

Triggered when user clicks "Confirm ICP" in the wizard
Payload: { user_id, icp_id, lead_list_id }

Pages & Routes
1. / — Landing Page
Design direction: Dark theme. Sharp, editorial. Think a cross between Linear and Stripe — but with more personality. NOT purple gradients. Use deep charcoal (#0E0E0E) background, off-white text, and a single sharp accent color (electric amber #F5A623 or acid green #AAFF00 — pick one and commit). Typography: use a bold condensed display font (e.g. Bebas Neue or Barlow Condensed) for headlines paired with DM Sans for body. Must feel like it was designed by a human who cares.
Sections:

Hero: Bold headline ("Stop stitching tools. Start selling."), subheadline explaining the value prop, single CTA button "Get Early Access" → scrolls to waitlist or routes to /signup
Problem: Short punchy section — "The average founder juggles 8–12 tools just to run outbound. Most never start. Most who do, start wrong." Use a visual showing the fragmented tool stack.
How it works: 4 steps with icons — Enter URL → AI analyses your business → Confirm your ICP → Get leads + stack. Clean numbered flow, not bullet points.
Stack preview: Show tool cards (Apollo, Instantly, Expandi, HubSpot etc.) as "what we recommend and set up for you"
CTA section: "You're one URL away from your first campaign." + signup button
Footer: Minimal. Logo, copyright, links.

No fake testimonials. No stock photos. No lorem ipsum.

Stack Recommendation Decision Tree Logic
Build this as a utility function lib/stackLogic.ts:
IF email_enabled:
  → recommend 'apollo' (leads, mvp)
  → recommend 'instantly' (email, phase2)
  → recommend 'mailreach' (warmup, phase2)

IF linkedin_enabled:
  → recommend 'apollo' (leads, mvp) -- if not already added
  → recommend 'expandi' (linkedin, phase2)

IF monthly_lead_target >= 50:
  → recommend 'hubspot' (crm, phase2)

IF email_enabled AND linkedin_enabled:
  → recommend 'slack' (alerts, phase2)

ALWAYS recommend:
  → 'apollo' (leads, mvp)
Save the output as a JSONB array in stack_recommendations.tools:

  {
    "slug": "apollo",

    "category": "leads",
    "reason": "Best source for B2B leads matching your ICP",
    "is_required": true,
    "phase": "mvp"
  }
]

Real-time Polling Logic
For both loading states (website analysis and lead generation):
typescriptconst pollStatus = async (table: string, id: string, field: string) => {
  const interval = setInterval(async () => {
    const { data } = await supabase
      .from(table)
      .select(field)
      .eq('id', id)
      .single()

    if (data?.[field] === 'complete') {
      clearInterval(interval)
      // advance to next step
    }
    if (data?.[field] === 'failed') {
      clearInterval(interval)
      // show error state
    }
  }, 3000)
}
